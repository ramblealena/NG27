# NG27 — снежный хедер ПСЖР / Демалыс

Прототип новогодней анимации в хедере статьи:

- зацикленный снег из трёх видов снежинок (S / M / L);
- кликабельный снеговик: баунс, покачивание, взмахи ручками, развевающийся шарф и салют (2 с);
- компактный хедер при скролле с таймингами как на aviasales.ru/psgr (0.15 с высота, 0.3 с логотип);
- мобильная и десктопная версии, переключатель ПСЖР / Демалыс (aviasales.kz).
